# Machine Learning Zoomcamp

**A hands-on journey through machine learning, from foundational concepts to model evaluation and deployment.**

## 📌 About This Repository

This repository documents my learning journey through the **Machine Learning Zoomcamp**, a practical machine learning course by [DataTalks.Club](https://datatalks.club/).

It contains exercises, experiments, and coursework organised by module, demonstrating my progress in understanding and applying machine learning techniques using Python.

The goal is to develop practical skills in building, evaluating, and deploying machine learning models while strengthening my understanding of the underlying concepts.

## 📚 Learning Modules

| Module | Topic | Key Concepts |
|---|---|---|
| 01 | Introduction to Machine Learning | ML fundamentals, Python, data exploration |
| 02 | Regression | Linear regression, feature engineering, regularisation |
| 03 | Classification | Logistic regression, categorical variables, feature importance |
| 04 | Model Evaluation | Validation strategies, precision, recall, ROC-AUC |
| 05 | Model Deployment | Model serving, APIs, reproducible environments |
| 06 | Decision Trees | Decision trees, random forests, gradient boosting |

Each module provides an opportunity to apply theoretical concepts to practical machine learning problems.

## 🛠️ Technologies and Tools

The course explores tools commonly used in machine learning workflows, including:

- **Python** – Programming and machine learning development
- **NumPy** – Numerical computing
- **Pandas** – Data manipulation and analysis
- **Matplotlib** – Data visualisation
- **Scikit-learn** – Machine learning algorithms and model evaluation
- **Jupyter Notebook** – Interactive experimentation
- **Git and GitHub** – Version control and project documentation

Additional tools may be introduced as the course progresses.
